# 원본 표 서식 실측값 (한글 문서 → PDF, A4, pdfplumber로 측정)

| 요소 | 값 |
|---|---|
| 글꼴 | 함초롬돋움(HCR Dotum) 보통/굵게 — 없으면 맑은 고딕 → 시스템 고딕 |
| 표 너비 | 487pt = 구분 70pt + 고지 417pt, 바깥 세로선 없음, 가운데 세로선 0.4pt |
| 머리행 | `구분` / `개인정보 수집·이용·제공 동의 및 제3자 제공 등 고지`, 13pt 굵게 가운데, 배경 #DFE6F7, 높이 약 18.5pt, 위 1.1pt 실선, 아래 이중선(0.4pt 두 줄) |
| 본문 | 10pt, 줄 간격 13pt, 칸 왼쪽 여백 약 5pt, 양쪽 맞춤 |
| 업체 사이 | 이중선(0.5pt 두 줄, 간격 1.4pt) |
| 칸 안 구역 사이 | 수집·이용 ↔ 제3자 제공: 0.4pt 실선 / 제3자 제공 ↔ 국외 이전: 이중선 |
| 구분 칸 | 10pt 보통, 가운데·세로 가운데 |
| 수집·이용 1·2 | 번호 보통 + **항목명 굵게** + `: 값` 보통 (1번 두 번째 줄은 값 시작에 맞춤) |
| 수집·이용 3 | 번호 보통 + **`보유 및 이용 기간: `** 굵게 + 값 **12pt 굵게 밑줄**(0.5pt) |
| 수집·이용 4 | 10pt 보통, 둘째 줄 내어쓰기 약 14pt |
| 동의 체크 줄 | 칸 안쪽 약 6.5pt 들인 상자, 배경 #DFE6F7, 테두리 0.4pt, 높이 약 19~22pt, 10pt 굵게 가운데: `개인정보 수집·이용에 □ 동의합니다. □ 동의하지 않습니다.` |
| ◆ 제3자 제공 고지 | 제목 10pt 굵게 / 1·3번: 항목명 굵게 + 값 보통 / 2번 값 **11pt 굵게 밑줄** / 4번 값 **12pt 굵게 밑줄** |
| ◆ 국외 이전 고지 | 제목·1·3번 전부 10pt 굵게(값 포함) / 2번: 항목명 굵게 + 값 **빨강(#FF0000)**, 나라 부분 굵게 / 4번 값 12pt 굵게 밑줄 |
